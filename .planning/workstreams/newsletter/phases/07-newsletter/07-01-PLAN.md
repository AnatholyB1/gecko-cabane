## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01-01 | Spoofing | confirm/unsubscribe links | mitigate | HMAC-SHA256 over purpose:rowId:exp with NEWSLETTER_SIGNING_SECRET, timingSafeEqual after length check, 30-day expiry on confirm |
| T-07-01-02 | Tampering | subscribe payload | mitigate | zod schema: email max 254, locale/source enums, consent literal true; source 'reservation_form' and withdrawal sources rejected |
| T-07-01-03 | Information disclosure | subscribe response | mitigate | uniform { ok: true } for new/pending/active emails; no row id returned |
| T-07-01-04 | Denial of service / abuse | confirmation mail relay | mitigate | hashed per-IP 5/h and per-email 3/day limits (nl- prefixes), honeypot + fill time, no re-send within 24 h for a pending email |
| T-07-01-05 | Information disclosure | IP and geo | mitigate | IP used only as an HMAC rate-limit key, never inserted; country stored only as ISO alpha-2 and only for web sources |
| T-07-01-06 | Tampering | email HTML | mitigate | escapeHtml on every interpolation, stripLineBreaks on subject |
| T-07-01-07 | Elevation of privilege | migration 015 | mitigate | no new policy on the ledger, counter table RLS on with anon/authenticated revoked, RPC executable by service_role only |
| T-07-01-08 | Repudiation | consent proof | mitigate | append-only rows with consented_at, source, locale, consent_text_version; confirmation_sent_at claim recorded |
