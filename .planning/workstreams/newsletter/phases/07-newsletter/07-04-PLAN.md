## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| email link -> confirm page | untrusted query params r/e/s, prefetched by mail scanners |
| browser -> POST /api/newsletter/confirm | untrusted signed token |
| server -> Brevo API | secret API key, personal data leaves to a processor |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-04-01 | Spoofing | confirm POST | mitigate | HMAC verify with purpose 'confirm' and expiry before any DB read; constant-time compare |
| T-07-04-02 | Tampering | link prefetch | mitigate | GET page performs no read-for-write and no write; state change only on POST from the button (source-scan test) |

| T-07-04-05 | Information disclosure | BREVO_API_KEY | mitigate | read only in server module brevo.ts, no NEXT_PUBLIC prefix, never logged; Sentry messages carry status + path only |
