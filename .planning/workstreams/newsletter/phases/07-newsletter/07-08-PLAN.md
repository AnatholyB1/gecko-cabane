## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| email link / mail client -> unsubscribe POST | untrusted signed token, possibly automated one-click |
| Brevo -> POST /api/webhooks/brevo | internet-facing server-to-server endpoint |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-08-01 | Spoofing | forged webhook | mitigate | bearer token (or URL token) compared with timingSafeEqual; fail closed when unset; 401 before body parse |
| T-07-08-02 | Tampering | forged unsubscribe of a third party | mitigate | HMAC-signed link bound to the row id and purpose 'unsubscribe' |
| T-07-08-03 | Tampering | link-scanner unsubscribe | mitigate | GET page never writes; only POST (button or RFC 8058 one-click POST) withdraws |
| T-07-08-04 | Information disclosure | unsubscribe page | mitigate | masked email only, response bodies never contain the email |
| T-07-08-05 | Repudiation | withdrawal proof | mitigate | append-only consent=false row with source and timestamp; idempotent |
| T-07-08-06 | Denial of service | webhook flood | accept | token required; each event is one indexed lookup; Vercel platform limits |
</threat_model>
