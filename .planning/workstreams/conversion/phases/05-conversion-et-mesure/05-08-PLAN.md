## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| internet -> POST /api/review/feedback | anonymous, attacker-controlled message/email/src/rid |
| route -> Resend -> owner inbox | user text is rendered in an email client |
| route -> Supabase (service role RPC) | rate-limit counter only |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-34 | Denial of service (inbox spam) | feedback POST | mitigate | honeypot fake success, 3 s fill time, zod length caps, 3 per hour per hashed IP via gecko_rate_limit_hit ('feedback:' bucket); invalid input does not consume quota |
| T-05-35 | Tampering (HTML / header injection) | owner email | mitigate | escapeHtml on every interpolated value, stripLineBreaks on subject, replyTo only after z.email() validation (tests) |
| T-05-36 | Information disclosure | message text / email | mitigate | not stored in DB (no .insert/.from, source-scanned), not sent to Sentry, not echoed in responses; privacy copy updated in 05-11 |
| T-05-37 | Spoofing (src/rid) | email metadata | accept | src allowlisted and rid UUID-checked; they are informational for the owner only, nothing is unlocked by them |
| T-05-38 | Elevation of privilege | service role | mitigate | used only for the security-definer rate-limit RPC with justification comment; route server-only |
| T-05-39 | Repudiation (silent loss) | Resend not configured | mitigate | Sentry.captureMessage when the client or recipient is missing; UI wording "transmis" never promises a reply |
