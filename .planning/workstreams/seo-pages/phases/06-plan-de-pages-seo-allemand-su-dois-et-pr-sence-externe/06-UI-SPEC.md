# Phase 6 — UI Design Contract

> Visual and interaction contract for the shared SEO landing-page component (4 EN pages + FR/DE/SV variants), the header "Guides" submenu (desktop + mobile), the "A decouvrir" cross-link block, footer links and the published-only language switcher. Generated by gsd-ui-researcher (auto mode, no questions asked), verified by gsd-ui-checker.
> Sources: 06-CONTEXT.md (D-01..D-18), 06-RESEARCH.md (Patterns 5-7, Pitfalls 4, 5, 9), 03-UI-SPEC.md (section D landing contract, inherited), `src/app/globals.css` gc-* tokens.
> Admin untouched. Docs deliverables in `docs/ph6/` have no visual contract.

## Design System

| Property | Value |
|----------|-------|
| Tool | none (shadcn deliberately not introduced; `gc-*` Tailwind v4 tokens are the system) |
| Preset | not applicable |
| Component library | none (hand-written Server Components; one small client component `GuidesMenu`, `LanguageSwitcher` stays client) |
| Icon library | lucide-react (already installed): `ChevronDown` for Guides toggle, `Menu`/`X` not needed (no hamburger), `ArrowRight` for cross-link cards |
| Font | Cinzel (headings, buttons, nav), Cormorant Garamond (body, prices), Raleway (labels, eyebrows, nav small caps); Cinzel Decorative for logo only. Same as Phase 3 |

Tailwind v4 syntax: `bg-gc-ivory`, `text-gc-text-dark`, `bg-(--gc-jungle)`; never `bg-[var(--x)]`. Legacy tokens (`--primary`, `--accent`) are admin-only. All visible strings via next-intl; no accented literal or banned phrase in `.tsx` (tests/i18n-hardcoded.test.ts).

Reuse, do not redefine: `BTN_GOLD`, `H2`, `PROSE`, `TEXT_LINK` constants from the existing french-restaurant page (move them into `src/components/seo/styles.ts` when factoring), `GcDivider`, `SiteHeader`, `SiteFooter`.

## Spacing Scale

Declared values (multiples of 4), identical to Phase 3 so landing pages stay visually consistent:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-text gap, chevron gap |
| sm | 8px | Gap between inline links, menu item icon gap |
| md | 16px | Paragraph spacing, card inner gap, button padding-y, dropdown item padding-x |
| lg | 24px | Container horizontal padding (mobile), card padding, footer column gap |
| xl | 32px | Grid gaps, button padding-x, gap between cross-link cards |
| 2xl | 48px | Gap between a section title block and its content |
| 3xl | 64px | Vertical padding of every landing section and band (mobile and desktop identical) |

Exceptions:
- Touch targets: Guides toggle, dropdown items, language switcher entries, cross-link cards, footer links have min-height 44px.
- Header height 64px (`h-16`) as on /menu and the landing page.
- Guides dropdown width 288px (`w-72`), anchored to the toggle on desktop; full-width panel on mobile (see below).
- Max content width: landing prose `max-w-3xl` (768px, ~65ch), grids `max-w-5xl` (1024px).
- Hero image aspect 16/9 desktop, 4/3 mobile.

## Typography

Four sizes, two weights, as in Phase 3 (no new sizes):

| Role | Size | Weight | Line Height | Font / notes |
|------|------|--------|-------------|--------------|
| Body | 16px | 400 | 1.7 (prose), 1.5 (card text, menu items) | Cormorant Garamond; card description may be italic |
| Label | 12px | 400 | 1.5 | Raleway uppercase, tracking 0.15em: eyebrows, nav small text, button labels, language codes |
| Heading | 20px | 600 | 1.2 | Cinzel: landing h2, card h3, Guides toggle and dropdown item text, footer column title |
| Display | 32px | 400 | 1.2 | Cinzel: single h1 per page |

Weights: 400 and 600 only. No 300 on 12px labels; no 700 except the existing logo. DE compound words: allow `hyphens-auto` and `overflow-wrap: break-word` on h1/h2/h3 and card titles (lang attribute is set by the locale layout); never shrink font size to fit.

Dark-jungle plus ivory palette from `globals.css`, 60/30/10 as Phase 3.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--gc-ivory` #FAF0E6 | Landing body sections, dropdown panel background |

| Accent (10%) | `--gc-gold` #C69B3C | See reserved list |

Text: `text-gc-text-dark` #1A0E00 headings, `text-gc-text-mid` #5C4A3A secondary text; `text-gc-ivory` on jungle. Eyebrow on ivory uses `text-gc-copper`; gold text only on jungle.

Accent reserved for:
1. Primary reservation CTA ("Book a table") in hero, closing band, "A decouvrir" block CTA, and the header Book button

3. `GcDivider` under the h1 and between sections
4. Eyebrow, logo and Guides toggle label on jungle backgrounds only

Gold is never used for body text, prose links on ivory, card titles, or the dropdown panel (ivory panel uses jungle text with gold only for the 2px active underline).

## Layout and Interaction Contract

### A. Shared landing template `SeoLandingPage` (all pages, all locales)

Inherits section D of 03-UI-SPEC.md. Fixed order; a page may omit a middle section but never reorder:

1. Header (see B) then Hero (jungle band, 64px vertical padding): eyebrow (12px label), single `<h1>` 32px, subtitle (16px), primary gold CTA to `/{locale}#reservation` and secondary ivory-outline link to the localized `/menu`. Hero image `next/image` `priority`, existing photo only (D-12), `object-cover`, alt from i18n.
2. Intro / content sections (ivory and parchment bands alternating, 64px vertical padding): `<h2>` 20px/600 with `GcDivider`, 1-2 paragraphs 16px/1.7 in `max-w-3xl`. Optional photo block per section: 4/3 image beside text on md+ (grid 2 cols, 32px gap, image side alternates left/right), stacked on mobile with image first. Photo blocks use only files already in `public/` (`exterior-*.jpg`, `food-*.jpg`, `chef-jariya.jpg`).
3. Page-specific blocks, all expressed as the same section primitives (no new layouts):
   - romantic-dinner: ambiance, table, occasion sections; a text link to the reservation form says the "occasion" field exists; no price, no formula, no stars (D-12).
   - where-to-eat-krabi-town: sections as neighbourhood/market/riverfront blocks with a 3-card grid (title + 1 sentence, no images, no competitor names, D-11); closing paragraph places Gecko for dinner.
   - getting-here-from-ao-nang: 2-column definition list on md+ (term 12px label, value 16px) for mode / typical duration / typical price; every number wrapped in an "approximate, confirm locally" qualifier string; if the owner has not supplied a figure the row is not rendered (never a placeholder).
   - wine-belgian-beer: pairing cards (dish type to style, generic style descriptions, no brand logos or labelled bottle photos), then a text link to `/menu#vins-bieres-belges` (anchor rendered only while that menu page is populated). No drink-promoting CTA (Pitfall 9).
4. "A decouvrir" block (see C), parchment band.
5. Closing CTA band (jungle, 64px): h2 20px/600 + gold "Book a table" button to `/{locale}#reservation`.
6. Footer (see D).

Structure rules: exactly one h1; h2 per section; h3 inside cards. If `contentLocales` excludes the locale the route renders `notFound()`. A page unpublished in its locale renders identically (noindex has no visual); it simply hides itself from switcher, Guides, cross-links and footer lists of other locales.

Buttons (inherited): min height 44px, 12px label Cinzel uppercase tracking 0.15em, padding 16px x 32px; gold border and text on dark with gold fill and `text-gc-void` on hover; on ivory jungle border/text, jungle fill and ivory text on hover. Transitions 150ms colour/border only.

### B. Header "Guides" submenu (PAGE-07, D-04)

Applies to `SiteHeader` and to the home page's own fixed nav (both get the same `GuidesMenu` client component). Header keeps: logo (left), Menu link, Guides toggle, LanguageSwitcher, Book button (right). No 7 links in the header: only Menu, Guides, Book are text controls.

Desktop (>= 768px):
- Toggle: `<button>` Cinzel 20px/600 ivory label "Guides" + `ChevronDown` 16px (rotates 180deg when open), min 44px tall, `aria-expanded`, `aria-controls="guides-menu"`, `aria-haspopup="true"` not used (it is a disclosure, not a role=menu; replace the home nav's `role="menubar"/menuitem` misuse with plain `<nav>` + list).
- Panel: absolute, below toggle, 8px offset, `w-72`, ivory background, 1px aged border, 16px padding, 8px between items; list of `<a>` links. Each item: label in Label role (12px Raleway uppercase, jungle), plus a one-line hint in Body role (16px Cormorant 400 italic, `text-gc-text-mid`), min 44px tall. Hover/focus: 2px gold underline under the label, no background change.
- Items: only pages published for the current locale (`guidesFor(locale)`, computed on the server, passed as `{label, href}[]` props); current page item has `aria-current="page"` and the 2px gold underline. Order: french-restaurant, romantic-dinner, where-to-eat, getting-here, wine-belgian-beer (items absent for locales that do not publish them).
- Behaviour: opens on click/Enter/Space (never hover-only); closes on Escape (focus returns to toggle), outside click, route change, or Tab leaving the panel. Focus ring 2px gold offset 2px on jungle; 2px jungle inside the ivory panel.
- If the list is empty for a locale (e.g. SV before any publication) the toggle is not rendered.

Mobile (< 768px):
- Header row shows logo, Guides toggle (label only, chevron), LanguageSwitcher (compact), Book button (uses `common.reserveShort`). Row must not overflow at 320px: below 400px the "Menu" text link is hidden in the header (it remains in the footer and in the Guides panel as first item).
- Panel opens as a full-width sheet under the header (position fixed, top 64px, left 0, right 0, ivory, 1px aged bottom border, max height `calc(100dvh - 64px)` with internal scroll), 24px horizontal padding, items 44px+ tall stacked with 8px gap, a 1px aged rule between items. Same close behaviour plus tap on a link. No animation other than opacity 150ms; respect `prefers-reduced-motion`.

Language switcher (Pattern 5): lists only `publishedLocales(currentPageKey)` plus the current locale (rendered as `aria-current="true"`, non-link when unpublished), each a real link to that locale's slug (`hreflang` attribute set); entries are 12px Raleway uppercase codes `FR EN DE SV`, 44px tall, 8px gap, current one with 2px gold underline. Fewer than 2 entries: render nothing (replaces the old `availableLocales` prop). On mobile the codes stay visible in the header (no dropdown) because at most 4 two-letter codes fit.

### C. "A decouvrir" cross-link block (PAGE-07)

- Placement: after the last content section, before the closing CTA band; parchment band, 64px vertical padding, `max-w-5xl`.
- Heading: h2 20px/600 with `GcDivider`.
- 2 or 3 cards in a grid (3 cols on md+, 1 col on mobile, 32px gap). Count = number of related pages published in the current locale, capped at 3 (RELATED map, `isPublished` filtered). If 0 are available the block is not rendered (never an empty heading).
- Card: whole card is one `<a>`, ivory background, 1px aged border, 24px padding, min height 44px (content makes it taller), contents: eyebrow 12px label (`text-gc-copper`), title h3 20px/600 (short `nav.*` label, not the SEO title), one-sentence description 16px/1.5 `text-gc-text-mid`, `ArrowRight` 16px at end of the row. Hover/focus: border becomes jungle, arrow moves 4px right (colour/transform 150ms; no movement under reduced motion). No hover-only information, no images.
- Directly under the cards (centered, 32px above): primary reservation CTA, ivory-surface variant (jungle border/text), label `Book a table` localized.

### D. Footer links

Footer keeps its current jungle surface. Add a "Guides" column titled in Heading role (20px/600 ivory) listing the same published pages as the Guides menu, plus Menu, and the existing privacy/credits/contact items. Layout: 3 columns on md+ (Navigate, Guides, Contact), single column on mobile with 24px gap between groups; links Body 16px ivory at 80% opacity-free colour (use `text-gc-ivory`, hover underline 1px), min 44px tall rows on mobile. TripAdvisor link uses `.com` URL from `seo.ts` (OPS-04). Links to unpublished pages are never rendered.

### E. Accessibility (all surfaces)

- Skip link retained; visible 2px focus rings (gold on dark, jungle on ivory).
- Disclosure pattern for Guides (button + `aria-expanded`), Escape closes; list is a `<ul>` inside `<nav aria-label>` localized.
- Language links carry `lang` and `hreflang` attributes; current page marked `aria-current`.
- Images: descriptive `alt` via next-intl, decorative dividers `aria-hidden`.
- Contrast AA (4.5:1 body, 3:1 for 20px+/600). Gold text never on ivory.
- Motion limited to 150ms colour/opacity; no smooth scroll under `prefers-reduced-motion`.
- DE/SV long strings: no truncation with ellipsis on nav or CTA; buttons wrap to two lines if needed (keep min-height, centered text).
