# Phase 3 — UI Design Contract

> Visual and interaction contract for /menu, the homepage menu teaser and light blocks, /en/french-restaurant-krabi, and the small /menu header. Generated by gsd-ui-researcher (auto mode, no questions asked), verified by gsd-ui-checker.
> Sources: 03-CONTEXT.md (D-01..D-14), 03-RESEARCH.md, `src/app/globals.css`, `src/components/MenuDisplay.tsx`, `src/app/[locale]/page.tsx`.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (React/Next project, shadcn deliberately not introduced; existing `gc-*` Tailwind v4 tokens are the system) |
| Preset | not applicable |
| Component library | none (hand-written Server Components) |
| Icon library | lucide-react (already used: `Leaf`, `Flame`; add `WheatOff` only if present in installed version, else fallback text badge "GF" in a 16px bordered square) |
| Font | Cinzel (headings, buttons), Cormorant Garamond (body, descriptions, prices), Raleway (labels, eyebrows, legend, nav); logo uses Cinzel Decorative as on the homepage |

Tailwind v4 syntax: `bg-gc-ivory`, `text-gc-text-dark`, `bg-(--gc-jungle)`; never `bg-[var(--x)]`. Legacy tokens (`--primary`, `--accent`...) are admin-only: do not use them on public surfaces.

## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-text gap, legend icon gap |
| sm | 8px | Picto cluster gap, item name/price row gap |
| md | 16px | Item-to-item gap, paragraph spacing, nav item padding-y |
| lg | 24px | Container horizontal padding (mobile), category header margin-bottom |
| xl | 32px | Gap between category blocks, card padding |
| 2xl | 48px | Gap between menu page sections, landing section inner gaps |
| 3xl | 64px | Landing and homepage block vertical padding (96px on desktop is NOT used: use 64px mobile, 64px desktop for new blocks) |

Exceptions:
- Touch targets: anchor nav links, header CTA and language switcher have min-height 44px (padding adds up to it).
- Sticky anchor nav height 48px (`h-12`); sections use `scroll-mt-28` (112px = header 64px + nav 48px) so headings are not hidden under the sticky bars.
- /menu header height 64px (`h-16`), smaller than the homepage 72px nav.
- Max content width: menu `max-w-3xl` (768px) single column for items, landing `max-w-5xl` (1024px).

## Typography

Four sizes, two weights for all new surfaces (existing homepage sections keep their current sizes; do not refactor them).

| Role | Size | Weight | Line Height | Font / notes |
|------|------|--------|-------------|--------------|
| Body | 16px | 400 | 1.5 (descriptions on menu), 1.7 (landing prose) | Cormorant Garamond; item descriptions use italic; prices use Cormorant 400, tabular figures |
| Label | 12px | 400 | 1.5 | Raleway, uppercase, tracking 0.15em; eyebrows, legend, anchor nav, allergens line, price_label |
| Heading | 20px | 600 | 1.2 | Cinzel; category (h3) and item names (h4); landing h2 uses the same 20px at 600 with tracking-wide |
| Display | 32px | 400 | 1.2 | Cinzel; h1 on /menu and landing, and menu page section titles (h2) |

Weights: 400 regular and 600 semibold only. Never `font-light` (300) on 12px labels (illegible on ivory); never bold (700) except the existing logo.
Item names are 20px/600 Cinzel but may wrap; allergens text is 12px Raleway 400 in `text-gc-text-mid`.

## Color

Public site uses the dark-jungle plus ivory palette from `globals.css`.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--gc-ivory` #FAF0E6 | /menu page background, landing body sections, item rows |
| Secondary (30%) | `--gc-parchment` #F5EEDA, `--gc-aged` #E8DCC8, `--gc-jungle` #0C3C2D | Parchment for alternate bands and legend box; aged for 1px dividers and borders; jungle for /menu header, landing hero band and footer |
| Accent (10%) | `--gc-gold` #C69B3C | See reserved list |
| Destructive | none in this phase (public pages, no destructive action) | not applicable |

Text colors: `text-gc-text-dark` #1A0E00 for names/headings; `text-gc-text-mid` #5C4A3A for descriptions/allergens (contrast above 7:1 on ivory); on jungle backgrounds `text-gc-ivory`. Picto colors stay as in MenuDisplay: `Leaf` `text-gc-celadon`, `Flame` `text-gc-copper`, gluten-free `text-gc-brass`. Eyebrow text on ivory uses `text-gc-copper` (gold fails contrast on ivory); gold text only on jungle backgrounds.

Accent reserved for:
1. Primary reservation CTA button (gold border, hover fill gold with `text-gc-void`) in /menu header, landing hero, landing closing band, and the "Voir la carte complète" teaser button
2. Active/hovered state underline (2px) of the sticky anchor nav link
3. Short gold divider (`GcDivider`) under h1 and between landing sections
4. Gold text for eyebrow/logo on jungle backgrounds only

Gold is never used for body text on ivory, prices, item names, links in prose, or picto icons.

## Layout and Interaction Contract

### A. `/[locale]/menu` (Server Component, all dishes in initial HTML)
- Header (jungle, 64px, not sticky-overlapping nav): logo link to `/{locale}` (left), LanguageSwitcher (center-right), reservation CTA to `/{locale}#reservation` (right; icon-less text button at 44px min height). On widths below 480px the CTA label shortens to the `common.reserveShort` key and the switcher stays visible.
- Hero strip (ivory): eyebrow (12px label), single `<h1>` 32px, one-line intro (16px italic Cormorant, `text-gc-text-mid`), then the legend box.
- Legend box (parchment, 1px aged border, 16px padding): inline list of Leaf "Végétarien"/Vegetarian, Flame "Épicé"/Spicy, gluten-free "Sans gluten"/Gluten-free. Gluten-free entry is rendered only if at least one item has `is_gluten_free = true` (D-04, no implied coverage). Always followed by an allergy line (12px label): "Allergies : demandez conseil à notre équipe." (translated; wording subject to owner approval, see Pitfall 9 of research). Legend text is real HTML text.
- Sticky anchor nav: `<nav aria-label>` with plain `<a href="#slug">` links, `position: sticky; top: 0` (below header which scrolls away on /menu), 48px height, ivory background at 95% with 1px aged bottom border, horizontally scrollable on mobile (`overflow-x-auto`, no wrap, no visible scrollbar, 8px gap, each link 44px tall, 16px horizontal padding). Labels come from DB `page.name` (French). Only active pages that have items appear; the Belgian page is absent until populated. No JS scroll-spy; focus ring 2px gold offset 2px.
- Sections: each page is `<section id={slug} class="scroll-mt-28">` with `<h2>` 32px Cinzel, optional DB description (16px italic), then categories. Category = `<h3>` 20px/600 Cinzel with optional 16px italic description; items in a `<ul>`.
- Item row: name `<h4>` 20px/600 left, then dotted leader (1px dotted aged border) filling to price right-aligned (`650 ฿`, Cormorant 16px, no `.00`, tabular numbers, `whitespace-nowrap`); picto cluster directly after the name (16px icons, 8px gap, each with `aria-label` plus `<span class="sr-only">` text); description below (16px italic, ALWAYS visible, never `opacity-0`/`group-hover`); allergens line below (12px label, prefix translated "Allergènes :"/"Allergens:"); `price_label` below price (12px label) when present. Item rows are separated by 16px; categories by 32px; sections by 48px with a 1px aged top rule.
- No hover-only information anywhere. Hover on item rows: none. Pictos are not interactive.
- Back-to-top link at page bottom (text link, 44px tall) to `#top`; footer minimal (copyright, link to privacy, creators credit as on home).
- Empty/loading: the page has no loading state (server rendered). If `getMenu()` returns no sections show the empty state in Copywriting. Fetch errors fall through to `error.tsx`.
- Mobile first: single column below 768px; nothing wider than viewport; icon+text stay on one line; prices never wrap under names (name wraps instead).

### B. Homepage `#menu` teaser (replaces `MenuDisplay`)
- Keep `id="menu"` and the existing section background/eyebrow/title/description pattern (eyebrow, h2 title, italic description).
- Teaser content: up to 4 text-only items from the Ardoise page (name 20px/600, price `฿` right, one-line description clamp 2 lines) in a 2-column grid (md) / 1 column (mobile), parchment cards with 24px padding and 1px aged border, no images, no pictos. Section below: primary gold-outline button "Voir la carte complète" to `/{locale}/menu` (via `Link` from `@/i18n/navigation`). If the Ardoise page has no items, show only the button and description.
- Main nav link "Menu" retargets to `/{locale}/menu` and an extra footer link is added for `/menu`.

### C. Homepage light blocks (PAGE-01, D-11)
- Reviews (inside or directly under the social/about band): one centered line "Note Google 4,7 / 5 · 1 062 avis" (20px/600 Cinzel number, 12px label for the rest) plus text link "Lire les avis sur Google" to the existing place URL (opens new tab, `rel="noopener noreferrer"`). No stars graphic, no quotes, no schema.
- Story: existing `#about` kept unchanged except verifying heading and keeping a text link to the landing page (EN locale only).
- Access: in `#contact`/`#hours` add a text button "Itinéraire Google Maps" (secondary style: ivory border, jungle text on ivory or ivory text on jungle) using the existing place URL. Address, hours remain the existing blocks.

### D. `/en/french-restaurant-krabi` (EN only, `notFound()` for other locales)
Order of sections (top to bottom):
1. Hero (jungle band, 64px vertical padding): eyebrow "Maharat Road, Krabi Town", `<h1>` 32px "French restaurant in Krabi Town" (exact phrase), subtitle 16px (authentic French cooking by a French-Thai couple), primary gold CTA "Book a table" to `/en#reservation` and secondary ivory-outline link "See the menu" to `/en/menu`. Hero image: `exterior-entrance.jpg`, `next/image` `priority`, aspect 16/9 desktop and 4/3 mobile, `object-cover`.
2. Intro (ivory): two paragraphs, 16px/1.7, max 65ch.
3. Signature dishes (parchment band): 4 cards in a 2x2 grid (md) / stacked (mobile): `food-bourguignon.jpg`, `food-veloute.jpg`, `food-poulet-creme.jpg` (French) and `food-massaman.jpg` (Thai); each card: image 4/3, h3 20px/600, one-sentence 16px description. Descriptive alt text through next-intl.
4. Belgian wines and beers (ivory): short paragraph and text link to `/en/menu` (fragment `#vins-bieres-belges` only once that page is active; no dead anchor).
5. The couple's story (parchment): `chef-jariya.jpg` (1:1 on mobile, 4:5 on desktop, left) and 2 paragraphs (right); no award or review claims.
6. Find us (ivory): address, opening hours summary from existing `getOpeningHours`, link "Get directions" (existing place URL), and phone/WhatsApp link only if already used on the homepage.
7. Closing CTA band (jungle): h2 20px/600 + gold "Book a table" button to `/en#reservation`.
- Header: same small header as /menu. LanguageSwitcher is hidden on this page (`availableLocales={['en']}`), since no FR page exists (D-14).
- Exactly one h1, h2 for sections 2-7, h3 inside cards. Only existing images listed in D-13; no new photos, no carousel, no video.
- `RestaurantJsonLd locale="en"` allowed; no Review/AggregateRating markup.
- Buttons: primary = gold border + gold text on dark, filled gold with `text-gc-void` on hover; on ivory use jungle border/text with jungle fill on hover to keep contrast. Min 44px height, 12px label font, Cinzel, uppercase, tracking 0.15em, padding 16px x 32px.

### Accessibility (all surfaces)
- Skip link as on homepage; visible focus rings (2px gold on dark, 2px jungle on ivory).
- Color is never the only carrier of meaning: every picto has adjacent legend text and sr-only text.
- Images: `alt` from i18n; decorative dividers `aria-hidden`.
- Motion: none beyond color/border transitions (150ms); respect `prefers-reduced-motion` (no smooth scroll if reduced).
- Contrast target WCAG AA (4.5:1 body, 3:1 for 20px+/600 headings).
