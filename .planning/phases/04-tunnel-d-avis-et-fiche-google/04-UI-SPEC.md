# Phase 4 — UI Design Contract

> Visual and interaction contract. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> Scope: (1) public page `/{locale}/review`, (2) review invitation email (Resend `baseTemplate`), (3) admin tracking badge on reservation cards (French fixed), (4) two print PDFs (bill insert, A6 table tent) FR/EN/DE.

## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gap inside buttons, badge inner gap |
| sm | 8px | Gap between stacked small texts, admin badge row gap |
| md | 16px | Gap between the two review buttons, email paragraph spacing |
| lg | 24px | Card inner section gaps, title-to-intro gap |
| xl | 32px | Card padding mobile (`p-8`), email cell padding |
| 2xl | 48px | Card padding `sm`+ (`p-12`) |
| 3xl | 64px | Page top/bottom padding |

Exceptions:
- Review buttons: min height 56px (`min-h-14`), full width, a multiple of 4 and above the 44px touch minimum.
- Email button: padding 16px 32px (min tap height 48px).
- Admin badges: `px-2 py-0.5` (8px / 2px), matching the existing `px-2 py-0.5 rounded` badges at lines 472/482 of the admin page; 2px is the single pre-existing off-scale value, not extended.
- Print: millimetre geometry (see Print section); safe margin 5 mm, bleed 3 mm.

## Typography

Exactly 4 sizes and 2 weights for the web page (same scale as Phase 1).

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body (intro, button helper text) | 17px Cormorant | 400 | 1.5 |
| Label (button text Cinzel, tracking 0.1em, uppercase) | 11px Cinzel on desktop; see note | 500 | 1.5 |
| Small (reassurance line, footer link) | 14px Cormorant italic | 400 | 1.5 |
| Heading (page title) | 20px Cinzel, `tracking-wide` | 400 | 1.2 |

Notes:
- Button text uses 14px Cinzel uppercase tracking 0.1em weight 500 on the review page for legibility on phones: this is the "Small" size (14px), not a fifth size. The 11px Label size is reserved for the "Gecko Cabane" overline above the title (Raleway, uppercase, tracking 0.2em).
- Weights: 400 and 500 only. No `font-bold`.
- Email sizes (inline styles, separate scale from web): title 20px normal weight, body 15px line-height 1.6, small 13px italic, button 14px weight normal uppercase letter-spacing 2px. Same as existing `baseTemplate` usage.
- Admin badges: 12px (`text-xs`), `font-medium`, per existing admin conventions (admin has its own Tailwind default scale; not subject to the public 4-size rule).

Accent reserved for:
1. Primary button fill on `/review` (Google button): `bg-gc-jungle`, hover/focus `bg-gc-void`, ivory text
2. Gold rule above the page title (`w-10 h-px bg-gc-gold`) and gold corner ornaments on the card (same as form card)
3. Focus ring on both buttons: `focus-visible:ring-2 ring-gc-gold ring-offset-2 ring-offset-gc-parchment`
4. Email: the single CTA button fill (#0C3C2D, text #FAF0E6) and the gold overline "Gecko Cabane" (#C69B3C) already in the header
5. Print: gold hairline fold line / ornament rule (#C69B3C) only

Rules:
- Second button (TripAdvisor) is secondary-styled, NOT accent: transparent background, `border border-gc-jungle`, `text-gc-jungle`, hover `bg-gc-jungle/10`. - No star-rating graphics, no "5 stars" imagery, no wording that steers toward a positive rating (no pre-filtering, D-12/D-18).
- Email: reuse hex values already in `baseTemplate` (#F5EEDA, #FAF0E6, #E8DCC8, #0D1F17, #C69B3C, #1A0E00, #5C4A3A). No new colors.
- Contrast: ivory on jungle ~11:1; jungle text on parchment ~10:1. Both pass AA.

## Component Contracts

### 1. `/{locale}/review` page (`src/app/[locale]/review/page.tsx`, Server Component)

Utility page. Locales `fr` and `en` only (de/sv resolved to `en` upstream by the alias handlers, D-10). `robots: { index: false, follow: false }`, no canonical/hreflang, not in sitemap (D-11). Text via `getTranslations({ locale, namespace: 'review' })`.

Layout (mobile first, designed at 360px):
- Full-height `bg-gc-void`, content vertically top-aligned on mobile with 64px top padding (`pt-16`), centered with `max-w-md` (448px) on `sm`+; horizontal page padding 16px.
- Card: `bg-gc-parchment border border-gc-aged`, padding `p-8 sm:p-12`, gold corner ornaments identical to ReservationForm card / `/privacy` panel.
- Order inside card, top to bottom:
  1. Overline "Gecko Cabane" (11px Raleway uppercase, tracking 0.2em, `text-gc-text-mid`), centered
  2. Gold rule 40px x 1px, centered, 16px below
  3. `<h1>` Heading (20px Cinzel, `text-gc-text-dark`, centered), 16px below the rule
  4. Intro paragraph (17px Cormorant, `text-gc-text-dark`, centered, `max-w-[34ch]`), 16px below the title
  5. Button stack (`flex flex-col gap-4`), 24px below intro: Google, then TripAdvisor (DOM order = visual order = tab order)
  6. Reassurance line (14px Cormorant italic, `text-gc-text-mid`, centered), 24px below buttons
  7. Back link to home (14px, jungle underline, 44px tap height), 16px below. Locale-aware `Link` from `@/i18n/navigation`.
- No header navigation, no WhatsApp floating button overlap concern: the Phase 1 floating button mounts in `[locale]/layout.tsx` and stays; the card gets `pb-24` equivalent via page bottom padding `pb-24 sm:pb-16` so the button never covers the last link.

Buttons (both are `<a>`, not `<button>`):
- `href` from `googleReviewUrl()` / `tripAdvisorReviewUrl()` (centralised in `src/utils/seo.ts`), `target="_blank"`, `rel="noopener noreferrer"`. Works without JS.
- Size: full width, `min-h-14` (56px), `px-6`, flex row centered, glyph 20px + 8px gap + label.
- Google: primary fill (see Color). TripAdvisor: outlined secondary.
- Label includes the platform name so the destination is unambiguous: "Avis sur Google" / "Review on Google"; "Avis sur TripAdvisor" / "Review on TripAdvisor".
- Trailing external-link affordance: 16px inline SVG arrow (`aria-hidden`), plus visually hidden text "(s'ouvre dans un nouvel onglet)" / "(opens in a new tab)" appended via `sr-only`.
- States: default; hover (Google `bg-gc-void`, TA `bg-gc-jungle/10`); focus-visible gold ring; active `translate-y-px`; transition 200ms colors only; no animation (reduced motion safe). No loading state (plain navigation). No disabled state.

States of the page:

| State | Behaviour |
|-------|-----------|
| Default (valid or absent `rid`) | Identical rendering. The page never reveals whether `rid` was valid (D-13/D-14) and never shows guest data (no first name greeting). |
| Invalid / malformed / unknown `rid` | Renders normally, no write, no error. |
| DB write failure on click mark | Swallowed (try/catch); buttons still render. |
| JavaScript disabled | Fully functional (no client component on this page). |
| Empty / error states | Not applicable: no data list, no form. |

Accessibility: one `h1`, `<main>`, `lang` follows locale, buttons keyboard reachable in visual order, contrast verified above, 56px targets, `sr-only` new-tab notice, `rel` hardening. Print/SEO: not applicable.

### 2. Review invitation email (`reviewInvitationEmail(locale, url, kind)` in `src/utils/resend.ts`)

Uses `baseTemplate` unchanged (520px max width, void header with gold overline "Gecko Cabane" and tagline, ivory body, aged footer). `locale` is `fr` or `en` (de/sv fall back to `en`, D-08). `kind` is `invite` (J+1) or `reminder` (J+5).

Body structure, in order:
1. `<h1>` title (20px Georgia normal, #1A0E00)
2. One short paragraph (15px, line-height 1.6, #5C4A3A, max 2 sentences): thanks for visiting + one-line ask. Reminder variant: one sentence, softer, acknowledges it is the only reminder.
3. Single CTA button, centered, table-based bulletproof button: background #0C3C2D, text #FAF0E6, padding 16px 32px, 14px uppercase, letter-spacing 2px, no border radius, `href` = `{SITE_URL}/review?rid={review_token}&src=email`. Label "Donner mon avis" / "Leave a review".
4. Plain-text URL fallback line below the button (13px italic #5C4A3A) so the link is usable when buttons are stripped.
5. Footer sentence in the existing footer slot: reservation context line ("Vous recevez ce message suite à votre réservation au Gecko Cabane.") and the restaurant contact. No marketing content, no promo, no unsubscribe-for-newsletter language (this is transactional, RESEARCH Pitfall 8).

Rules:
- Subject: short, no emoji, no "!" , no capitals shouting: 40 characters or fewer. Passed through `stripLineBreaks`.
- Customer name (if used for greeting) passes through `escapeHtml`. Greeting uses first name only; if empty, omit the greeting rather than writing "Bonjour ,".
- Exactly one link/button. No images. No tracking pixel. Plain text alternative provided with the same URL.
- No incentive wording (D-18): forbidden words list for copy review: remise, offert, cadeau, gagner, discount, free, gift, win, reward, "5 étoiles", "5 stars".
- Email-client safety: inline styles only, `role="presentation"` tables, width via `max-width:520px`; dark-mode neutral (explicit background colors set on every cell).

### 3. Admin tracking badge (`src/app/admin/reservations/page.tsx`, French fixed, no i18n)

Placement: on each reservation card, in the existing meta row with the other small badges (where `px-2 py-0.5 rounded` badges sit at lines ~472-482), only for statuses `confirmed` and `completed`. Never rendered for `pending`, `cancelled`, `no_show`, nor when `customer_email` is empty (show the "Pas d'email" badge instead, see below).

Badge shape: reuse the existing pattern `px-2 py-0.5 rounded text-xs font-medium inline-flex items-center gap-1`, no icons beyond a 12px inline SVG dot/check (`aria-hidden`). Dates in `fr-FR` short format `17 oct.`, Krabi time zone (`Asia/Bangkok`, UTC+7), via `toLocaleDateString('fr-FR', { day: 'numeric', month: 'short', timeZone: 'Asia/Bangkok' })`.

| State (from columns) | Label | Style |
|----------------------|-------|-------|
| `review_email_sent_at` set, not clicked, no reminder | `Invitation envoyée le {date}` | `bg-blue-100 text-blue-700` |
| `review_reminder_sent_at` set (and not clicked) | `Rappel envoyé le {date}` (shown in addition to the invitation badge) | `bg-amber-100 text-amber-700` |
| `review_clicked_at` set | `Lien cliqué le {date}` | `bg-green-100 text-green-700` |
| Eligible, service date passed, nothing sent yet | `Invitation prévue demain 11h (Krabi)` when date is yesterday or today per Krabi calendar; otherwise omitted | `bg-gray-100 text-gray-600` |
| No `customer_email` on a `confirmed`/`completed` reservation | `Pas d'email : aucune invitation` | `bg-gray-100 text-gray-600` |

Display order: invitation, reminder, clicked (chronological). Max 3 badges, wrap with `flex-wrap gap-2`. Each badge has a `title` attribute with the full date and time ("Envoyée le 17 oct. 2026 à 11:12").

No-show deadline note (D-03): on `confirmed` cards whose service date is today or yesterday (Krabi), a one-line hint under the action buttons, 12px, `text-amber-700`: `Non présenté ? À marquer avant 11h (Krabi) le lendemain du service : l'envoi peut avoir lieu entre 11h et 12h.` Once `review_email_sent_at` is set the hint disappears and the existing "Non présenté" button remains (no behavioural change; marking after send just stops the reminder, D-09). The existing "Terminée" / "Non présenté" buttons are untouched.

Admin states: loading and error states of the page are unchanged. Badges render nothing while data is loading. The `review_token` is never displayed.

### 4. Print assets (`scripts/generate-review-print.mjs` -> `docs/print/`)

Deliverables: `review-qr.svg`, `review-addition-insert.pdf`, `review-chevalet-a6.pdf`. Generated by script, committed (D-15/D-16). QR encodes exactly `https://geckocabanerestaurant.com/review?src=qr`, error correction M, quiet zone 4 modules, QR drawn as vector rects, dark `#0D1F17` on light `#FFFFFF`/ivory `#FAF0E6`-free white box (QR always on a pure white square for scan reliability).

Common print rules:
- Bleed 3 mm on all sides, crop marks outside bleed, safe zone 5 mm inside trim. Fold line (chevalet) drawn as 0.25 pt dashed gold hairline in the non-printing margin only (outside trim), not on the artwork.
- QR minimum printed size 28 mm square (above the 25 mm floor), centered horizontally in its panel.
- Typographic scale for print (points): Heading 16pt Times-Roman, Body 11pt Times-Roman line-height 1.4, Label 8pt Helvetica uppercase tracking 1.5pt, URL caption 8pt Helvetica. Two weights only: regular Times-Roman and Helvetica (no bold).
- Colors: text `#0D1F17`, secondary text `#5C4A3A`, accent rule `#C69B3C`, background white or `#FAF0E6`. CMYK conversion left to the printer; no gradients, no transparency.
- No incentive, discount or rating-steering language (D-18). Text blocks are three languages stacked in order FR, EN, DE, separated by a 0.5 pt `#E8DCC8` rule. DE block marked "à relire" ONLY in the sidecar note `docs/print/README.md`, never on the artwork (RESEARCH). The owner validates DE before printing (D-17).

Bill insert (`review-addition-insert.pdf`): trim 100 x 60 mm landscape; left 38 mm = QR panel (QR 28 mm + 4 module quiet zone, caption `geckocabanerestaurant.com/review` 8pt below), right = FR/EN/DE copy. Gold 8 mm rule above the FR heading. Fits inside a bill folder.

Table tent (`review-chevalet-a6.pdf`): one sheet 105 x 296 mm trim (two A6 faces 105 x 148 mm, fold at 148 mm), face A (front) = QR 36 mm centered + one-line heading in FR/EN/DE + URL caption; face B (rear, rotated 180 degrees so it reads upright when folded) = same content, so both sides of the table can scan. Overline "Gecko Cabane" (8pt Helvetica uppercase tracking) and gold rule on each face.

Copy (final text lives in the Copywriting Contract below; the script reads constants, not inline strings).

## Accessibility and Interaction Requirements

- `/review`: one `h1`; both CTAs are links with descriptive text; 56px targets; visible gold focus ring; works at 320px width without horizontal scroll; no motion beyond 200ms color transitions.
- Order of actions is Google then TripAdvisor in DOM, visually and by tab (D-12); both always rendered (no hiding of either).
- Email: text alternative and visible URL fallback; sufficient contrast; single CTA; no reliance on images.
- Admin: badges are text, not color-only (every state has a label); `title` for full timestamps.
- Print: QR scannable at 28 mm; quiet zone respected; tested by scanning a printed or on-screen proof with iOS and Android cameras before the print run (owner step).
- Device test before 1 Nov (RESEARCH): the owner opens both buttons on a real phone; links are centralised so they can be swapped without touching the UI.
