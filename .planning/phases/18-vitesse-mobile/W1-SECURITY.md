## Constats vérifiés sans défaut

1. Middleware (compare `master`) : la branche admin/API/auth est identique (getUser, `gecko_is_admin`, signOut local, redirect `?redirect=`, cookies réappliqués par `withCookies`). Seul changement : `public` passe par intl sans Supabase, `alias` et `monitoring` en `NextResponse.next()`. Prouvé : /admin, /admin/reservations, /admin/./reservations, /admin/../admin, /admin%2Freservations, /admin;x, /admin.json, `/%2e%2e/admin/reservations`, `/fr/%2e%2e/admin/reservations` donnent tous 307 vers /admin/login. `/admin/` et `//admin` : 308 vers /admin puis garde. /Admin, /ADMIN/*, /%61dmin/*, /adm%69n : redirigés par intl vers /fr/... puis 404 (le routeur Next est sensible à la casse et ne mappe pas ces chemins sur /admin). /fr/admin, /fr/api/settings, /fr/auth/callback : 404. `/api/reservations`, `/api/kpi`, `/api/cron/weekly-kpi` : 401 sans jeton ; /auth/callback sans code : 307 /admin/login?e=invalid. /admin/login et /admin/invitation 200 (pages publiques attendues).
2. Cache public : /fr, /fr/menu = ISR sans donnée de session (aucune lecture de cookie/headers dans les pages SSG ; getMenu/getOpeningHours via `unstable_cache`). /fr/review, /fr/newsletter/confirm, /fr/newsletter/unsubscribe (jetons dans searchParams) : `private, no-cache, no-store` car dynamiques via `searchParams`/`headers()`. /fr/wifi, /en/wifi : `private, no-store` ; /de/wifi, /sv/wifi : no-store (voir BAS). /admin/login : no-store. Alias /review /avis /bewertung /newsletter /wifi : redirections 307 `private, no-store`, query filtrée par liste blanche. Aucun nonce (pas de CSP encore : à revoir avec B20b, un nonce impose le rendu dynamique et casserait le cache).
3. En-têtes : les 4 en-têtes présents sur /fr, pages utilitaires, /admin/login, OG image. X-Frame-Options SAMEORIGIN : le site n'est jamais encadré ; l'unique iframe (`MapEmbed`) est sortante, non concernée. `/monitoring` : exclu du matcher et `classifyPath`, 404 en local sans DSN (envoi POST non testé). OG image `/fr/opengraph-image` : 200, image/png, nosniff, inchangée. `/gcm/js/script.js` : en-tête de cache public sans risque (script tiers, pas de donnée utilisateur) ; rewrite non testable sans variable Plausible.

Deux seuls `dangerouslySetInnerHTML` dans `src` (MenuJsonLd, RestaurantJsonLd), tous deux via `serializeJsonLd`. Aucun avis ni note inventé dans `menu-jsonld.ts`.
