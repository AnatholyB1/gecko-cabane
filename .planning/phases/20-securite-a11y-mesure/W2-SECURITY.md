## Constats vérifiés sans défaut

1. CSP : présente sur pages publiques, admin, 404, redirections 307 middleware, API, assets (voir BAS), pas sur les 308 de config. Texte exact en production : `default-src 'self'; script-src 'self' 'unsafe-inline'; style-src 'self' 'unsafe-inline'; img-src 'self' data: blob:; font-src 'self' data:; connect-src 'self'; frame-src https://www.google.com; manifest-src 'self'; object-src 'none'; base-uri 'self'; form-action 'self'; frame-ancestors 'self'`.
2. Réécriture 404 : la locale vient d'une regex stricte `(fr|en|de|sv)` (`middleware-routing.ts`), le chemin cible est construit de constantes, la query n'est pas lue par la page. En-têtes `x-middleware-rewrite`, `x-middleware-subrequest` (valeurs CVE-2025-29927), `x-forwarded-host`, `x-middleware-override-headers`, `Host: evil.example` envoyés sur /admin et /fr/nope : /admin reste 307 vers login, pas de rewrite détourné, 404 stable. `/fr/%0d%0aX:y`, `%00`, `\`, `?x=<script>` : 404 propre, query encodée. Aucune réponse 404 en cache public.
3. Cache public : /fr, /fr/menu = `s-maxage=3600`, aucun `Set-Cookie` (localeCookie:false prouvé), `Vary` standard Next. wifi : `/fr|en|de|sv/wifi` tous `private, no-store` (prouvé) ; `/fr/wifi/` et `//wifi` redirigent (308) vers la forme couverte ; `/FR/wifi` 307 no-store ; `/fr/%77ifi`, `wifi%2F` : 404 no-store, jamais le mot de passe. /fr/review, /fr/newsletter/confirm, /admin/login : no-store. Alias /wifi : 307 no-store, redirection construite sur request.url (Host d'infra).
4. Middleware vs master : branche session/admin identique (getUser, `gecko_is_admin`, signOut local, cookies réappliqués). `/admin`, `/fr/%2e%2e/admin` : 307 `/admin/login?redirect=%2Fadmin`. `/fr/admin` : 404 (pas d'accès à l'admin sous préfixe locale). `/api/hours` 200 public attendu.
5. Secrets : grep des noms (SUPABASE_SERVICE_ROLE, RESEND, SENTRY_AUTH_TOKEN, NEWSLETTER_SIGNING_SECRET, WIFI_PASSWORD, CRON_SECRET) et des valeurs de `.env.local` (non affichées) dans `.next/static` : 0 correspondance. HTML de /fr, /fr/menu, /de, /sv/wifi : 0 occurrence de SERVICE_ROLE ou WIFI_PASSWORD.
